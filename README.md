# Regis and Savoy Corporate Services LLP

Marketing website for **Regis and Savoy Corporate Services LLP** — an
animation-rich, AZB-inspired site skinned in the Regis & Savoy heritage
identity (crimson crest, warm ivory, aged gold, Cormorant Garamond).

## Repository layout
- `web/` — the Next.js 16 + React 19 application (App Router, Tailwind v4,
  Framer Motion, Lenis smooth-scroll)
- `content/` — source brand assets (logo PDFs, company profile document)

## Run the site
```bash
cd web
npm install
npm run dev      # dev server
npm run build    # production build (all routes prerender static)
```

See [`web/README.md`](web/README.md) for full details.
